Lecture 1 · HTML

HTML Basics

HTML (HyperText Markup Language) describes the content of a web page using tags. Each page on a website is one HTML file.

1.1HTML files and tags

HTML files

  • Each web page = one HTML file
  • Written in plain ASCII text (Notepad works)
  • Extension: .html or .htm

Tags

  • Usually come in two parts: opening <html> and closing </html>
  • The pair marks off text and says how to format it
  • Most tags support attributes

DTD (Document Type Definition)

A collection of rules written in SGML (Standard Generalized Markup Language). HTML is defined by its DTDs: all details of tags, entities and document structure live there.

Element

A part of the document's structure, like a title, a paragraph or a list. It includes the opening tag, the closing tag and the content in between.

Remember: how a page looks also depends on the browser settings, and on the user's system and monitor.

1.2Basic page structure

The page as a family tree every tag sits inside its parent
<html> — the root, wraps everything
<head> — invisible info
<title><meta><style><link>
Shown on the tab, read by the browser
<body> — what visitors see
<h1>…<h6><p><a><img><ul> <ol><table><form>

<head>

Information about the page: title, styles, meta. Not shown in the page body.

<title>

Text shown on the browser tab.

<body>

Everything the visitor sees: headings h1–h6, paragraphs p, images, links.

1.3Hyperlinks: <a href>

<a> means anchor. href means hypertext reference: it holds the URL you link to. By default a link is blue and underlined.

1.4Text formatting

<font> tag (old way)

Three attributes: color, size, face. The size is relative to the text before it.

CSS (preferred way)

Define a style rule once, then reuse it with a class.

?Likely exam questions

What is HTML? What extension do HTML files use?

HTML (HyperText Markup Language) is the markup language that describes the content of a web page using tags. HTML files are plain ASCII text with the extension .html or .htm.

Define DTD and Element.

DTD: Document Type Definition, a collection of rules written in SGML. HTML is defined by its DTDs, which describe all tags, entities and document structure.

Element: a component of a document's structure (title, paragraph, list) made of the opening tag, the content and the closing tag.

What do <a> and href stand for? Write a link to a file in the parent folder.

<a> = anchor, href = hypertext reference. Parent-folder link: <a href="../file2.htm">File 2</a>

Difference between relative and absolute links?

A relative link gives the path from the current file (file.html, sub/file.html, ../file.html). An absolute link includes the entire URL (http://site.com/page.html).

Why is CSS preferred over the <font> tag?

With CSS you define the style once and reuse it everywhere with a class, so changes happen in one place. The font tag must be repeated on every piece of text.

Advanced HTML & HTML5

Clickable image maps, the new HTML5 elements and attributes, plug-ins, and built-in audio/video.

2.1Image maps

An image map makes clickable areas on one image. Three steps:

1 · <img usemap>

Add usemap="#workmap" to the image.

2 · <map name>

name="workmap" must match the usemap value (without #).

3 · <area>

Each clickable area: shape, coords, href, alt.

rect → coords = top-left x,y , bottom-right x,y circle → coords = center x,y , radius

New elements

<header>, <footer>, <section>, <article> …

New attributes for <input>: autofocus, required, placeholder.

Two-way live connection; libraries like Socket.io make it easier.

Server-Sent Events (SSE)

Server pushes updates; widely supported but more limited than WebSockets.

A 2D drawing surface you program with JavaScript (e.g. 2D games).

Embed media without a plug-in.

Visitors can choose to share their physical location.

2.5Plug-ins, video and audio

Plug-ins

Helper programs that extend the functionality of a browser (PDF readers, Flash, maps, virus scan, bank ID). Added with <object> or <embed>.

<object> vs <embed>

<object>: defines an embedded object, supported by all browsers. <embed>: embeds external applications, usually audio/video.

Why give video a width and height? The browser reserves the space while the page loads. Without them the layout jumps while the video loads. controls adds play, pause and volume.

Drag and Drop

“Grab” an object and drag it to another place. In HTML5 it is part of the standard and any element can be draggable.

Geolocation

Gets the user's position with getCurrentPosition(). Because of privacy, it only works after the user approves.

?Likely exam questions

What is an image map? Write the code for a circular clickable area.

An image with several clickable areas, each linking somewhere. <area shape="circle" coords="337,300,44" href="coffee.htm" alt="Coffee"> — center x, center y, radius.

List any five new features of HTML5.

New semantic elements (header, footer, section, article), Forms 2.0 attributes, Canvas, Audio & Video, Geolocation, Drag & Drop, WebSockets, Server-Sent Events.

Difference between placeholder and required?

placeholder only shows a hint inside the box. required stops the form from being submitted while the field is empty.

What is a plug-in? Which tags add one?

A helper program that extends the standard functionality of a browser. Added with <object> or <embed>.

Why is Geolocation not available automatically?

It can compromise user privacy, so the browser shows the position only if the user approves.

Lecture 3 · HTML

Tables

A table is a grid of rows and columns, like a spreadsheet. Know these five tags and two attributes and you can write any table.

3.1The building blocks

<table>

Defines the table.

<tr>

Table Row.

<td>

Table Data (a normal cell).

<th>

Table Heading cell: bold and centered.

<caption>

Title shown above the table.

<thead> <tbody> <tfoot>

Group header, body and footer rows.

Order to remember: table → row → cell. A <td> always lives inside a <tr>; there is no “column” tag.

3.2colspan and rowspan (merge cells)

Same as “merge cells” in Excel. Both are attributes of <td> and <th>.

Common mistake: when a cell has rowspan="2", the next row has one fewer <td>, because the merged cell already fills that spot.

3.3caption, thead, tbody, tfoot

Notice: <tfoot> is written before <tbody> in the code, but the browser still shows it at the bottom.

?Likely exam questions

Difference between <th> and <td>?

<th> is a header cell (bold, centered by default). <td> is a normal data cell.

What are rowspan and colspan?

Attributes of td/th that make a cell span several rows (rowspan=x) or several columns (colspan=x). They work like “merge cells” in Excel.

Write a table: one heading cell spanning 2 columns, then a row with 2 cells.

<table border="1"><tr><th colspan="2">Marks</th></tr><tr><td>Ali</td><td>90</td></tr></table>

What is the use of <caption>, <thead> and <tfoot>?

caption gives the table a title. thead, tbody and tfoot group the header, body and footer rows so they can be styled and handled separately.

HTML Forms

Forms collect data from visitors (name, email, password) and send it to a back-end program such as CGI, ASP or PHP, which processes it.

4.1The <form> tag and its attributes

AttributeMeaning
actionThe back-end script that will process the data.
methodHow data is sent: GET or POST.
targetWhere to show the result: _blank, _self, _parent, …
enctypeHow data is encoded. application/x-www-form-urlencoded = standard (default). multipart/form-data = for uploading files (images, Word files).

4.2GET vs POST

GET

  • Data goes in the URL, visible in the address bar
  • Can be bookmarked and cached
  • Limited size (about 2048 characters)
  • For small, non-sensitive data like search
/submit?username=ali

POST

  • Data goes in the request body, not visible in URL
  • More secure: use for passwords
  • No strict size limit
  • For large or sensitive data
/submit (data hidden in body)
What actually travels to the server same form, two methods
method="GET"
example.com/submit?username=ali&city=lahore
Browser→data glued to the URL→Server
GET /submit?username=ali&city=lahore HTTP/1.1 Host: example.com (no body)

Anyone looking at the screen, the history or a bookmark can see the data.

method="POST"
example.com/submit
Browser→data sealed in the body→Server
POST /submit HTTP/1.1 Host: example.com username=ali&password=••••••

The URL stays clean; the data rides inside the request body.

Memory trick: GET is like a postcard (anyone can read it). POST is like a sealed envelope.

?Likely exam questions

Differentiate between GET and POST (4 points).

GET: data in URL / visible / can be bookmarked and cached / limited (~2048 chars) / not for sensitive data. POST: data in request body / hidden / not bookmarked / no strict limit / suitable for passwords.

Checkbox vs radio button?

Checkbox: more than one option can be selected. Radio: only one option out of a group (same name) can be selected.

Which enctype is used for file upload?

multipart/form-data. The default is application/x-www-form-urlencoded.

What is a hidden control and why is it used?

<input type="hidden"> keeps data inside the page (e.g. page number) that is sent to the server but never shown to the user.

Write a form with username, password and a submit button using POST.

<form action="/login" method="POST"> Username: <input type="text" name="user"> Password: <input type="password" name="pass"> <input type="submit" value="Login"> </form>

Lecture 5 · CSS

CSS Introduction

CSS (Cascading Style Sheets) controls how a page looks. HTML gives the content; CSS gives the style.

5.1What and why

History

  • Created by Håkon Lie (MIT) in 1994
  • Became the W3C standard for visual presentation of web pages
  • Works by letting you specify rules

Benefits

  • Saves time, easy to change
  • Keeps consistency across pages
  • More control over layout
  • Works with JavaScript
  • Common format for all pages
Why CSS was needed: HTML was meant to describe content, not format it. When <font> and color attributes were added in HTML 3.2, large sites became a nightmare to maintain. With one external .css file you can change the look of an entire website.

Best practice from the slides: put styles in external sheets wherever possible; use a global.css for the whole site, refine with section.css, and avoid styles inside tags.

5.3Anatomy of a CSS rule

A rule = selector (which elements) + declaration (how to style them). Each declaration = property : value, ending with a semicolon.

Element selector

p { } — all <p> elements

ID selector: #

#intro { } → <p id="intro">
For one unique element

Class selector: .

.center { } → <p class="center">
For many elements

Memory trick: # ID = your ID card, only one person has it. . class = a classroom, many students share it.

?Likely exam questions

What are the three ways to insert CSS? Give an example of each.

Inline: <h1 style="color:red">. Internal: <style> h1{color:red} </style> in head. External: a .css file linked with <link rel="stylesheet" type="text/css" href="mystyle.css">.

What is the cascading order?

1. Inline style (highest) 2. External and internal style sheets 3. Browser default (lowest).

Difference between ID and class selector?

ID (#name) styles one unique element. Class (.name) can be applied to many elements.

What does a CSS rule consist of?

A selector (the element(s) the rule applies to) and a declaration block of property: value pairs.

Lecture 6 · CSS3 Notes

CSS Properties, Layout & Responsive Design

The biggest lecture. Focus hardest on: box model, display, position, float, selectors, flexbox, media queries and units.

6.1Backgrounds, borders, margin & padding

Background

  • background-color
  • background-image
  • background-repeat: repeat-x, repeat-y, no-repeat
  • background-position: right top
  • background-attachment: fixed (does not scroll)
  • background: shorthand for all

Border

  • border-style: dotted, dashed, solid, double, groove, ridge, inset, outset, none, hidden
  • border-width: thin, medium, thick, px
  • border-color
  • Shorthand: border: 2px solid red; (style is required)
The 1-to-4 value rule (margin, padding, border): values go clockwise — top, right, bottom, left. margin: 10px 20px; = top/bottom 10px, left/right 20px. Memory trick: TRouBLe.

6.2The box model (play with it)

Every HTML element is a box: content → padding (inside border, transparent) → border → margin (outside border, transparent). width and height set the content size only.

margin

Exam formula: total width = width + left/right padding + left/right border + left/right margin. With box-sizing: border-box, padding and border are included in the width.

Width & height

Values: auto, length (px, cm), %. max-width overrides width and handles small windows better. Also min-width, max-height, min-height.

Outline

A line drawn outside the border. It is not part of the element's size. Properties: outline-style, outline-width, outline-color, outline-offset, outline (shorthand).

6.3Text, font and links

Text properties

  • color
  • text-align: left, right, center, justify

Font properties

  • font-family (give fallbacks, end with a generic family)
  • font-size: px, em, %. 1em = current font size, 16px by default
  • font-style: normal, italic, oblique
  • font-weight: normal, bold
  • font-variant: normal, small-caps
  • font: all in one
Link states MUST be in this order: LoVe HAte → :link, :visited, :hover, :active.

6.12Responsive Web Design (RWD)

RWD uses only HTML and CSS to resize, hide, shrink, enlarge or move content so the page looks good on any screen.

Viewport rules

  • Viewport = user's visible area of a page; varies by device
  • Do NOT use large fixed-width elements
  • Do NOT rely on one viewport width
  • Use media queries for small vs large screens

Grid view

Page divided into columns, usually 12 columns with total width 100%, shrinking and growing with the window. .col-1 {width: 8.33%} … .col-12 {width: 100%}. Use * {box-sizing: border-box}.

Media types & features

Types: all, print, screen, speech. Features: width/height of viewport or device, orientation (landscape/portrait), resolution.

Mobile first

Design for mobile before desktop, so the page displays faster on smaller devices.

Responsive images

width: 100% scales up and down. max-width: 100% scales down but never larger than original. background-size: contain / 100% 100% / cover.

<picture> element

Defines more than one image; the first <source> that fits is used. Frameworks: Bootstrap, Foundation, Skeleton, w3.css.

?Likely exam questions

Explain the CSS box model with a diagram.

Draw four nested boxes: Margin (outside) → Border → Padding → Content (inside). Content: where text/images appear. Padding: clear area around content, inside the border. Border: around padding and content. Margin: clear area outside the border. width/height apply to content.

Difference between margin and padding?

Margin is space outside the border (between elements). Padding is space inside the border (between border and content). Both are transparent.

Explain the four position values.

static (default, normal flow), relative (moved from its normal position, leaves a gap), fixed (relative to viewport, stays when scrolling), absolute (relative to nearest positioned ancestor, removed from flow).

Difference between display:none and visibility:hidden?

display:none removes the element; the page shows as if it isn't there. visibility:hidden hides it but it still takes up its space and affects the layout.

What is a media query? Write one.

A CSS3 technique using the @media rule to apply CSS only if a condition is true. @media only screen and (max-width: 500px) { body { background-color: lightblue; } }

Pseudo-class vs pseudo-element?

Pseudo-class (:hover) styles a special state. Pseudo-element (::first-letter) styles a specific part of an element. Pseudo-class uses one colon, pseudo-element uses two.

What is responsive web design and the viewport meta tag?

RWD makes pages look good on all devices using HTML and CSS only. The viewport meta tag <meta name="viewport" content="width=device-width, initial-scale=1.0"> sets the page width to the device width.
